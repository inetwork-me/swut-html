# Project rules

- **No corner radius.** All elements in this project must have square corners (radius 0). Do not add `rounded-*` values.
- **Exception — tag headlines are pills.** Every tag/eyebrow headline uses a full border all the way around with `rounded-full` (pill shape). No leading line/rule before the text. Pills are the ONLY element in the site allowed corner radius. Tag headlines use the default Nova `font-sans` — never `font-mono` or any font from outside the design system.
